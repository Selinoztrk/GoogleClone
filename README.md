# GoogleClone

A basic HTML and CSS template mimicking the Google search homepage.

---

## Project Structure

- **googlesearch.html**: Main search page layout.
- **imagesearch.html**: Alternative layout for image search.
- **style.css**: Shared styling for both pages.
- **google.jpg**: Placeholder image used in the design.

---

## Features

- Simple, responsive design.
- Mimics Google's search interface.
- Suitable for beginners learning HTML and CSS.

---

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Selinoztrk/GoogleClone.git
   ```
2. Open `googlesearch.html` or `imagesearch.html` in your browser to view the pages.
